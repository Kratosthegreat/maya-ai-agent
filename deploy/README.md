# להריץ את "קריירה" על Synology

המשחק הוא קובץ HTML אחד — `web/index.html`, מגה וחצי. אין שרת, אין
מסד נתונים, אין התקנה. כל מה שצריך הוא משהו שיגיש את הקובץ ברשת
הביתית, ואת זה ה-NAS עושה בלי מאמץ.

יש שתי דרכים. **Web Station היא הפשוטה** ולא דורשת שום דבר מהתיקייה
הזאת.

---

## הדרך הפשוטה: Web Station

1. **Package Center** → להתקין **Web Station**
2. Web Station → **Web Service** → *Create* → **Static website**
   - Document root: לבחור תיקייה, למשל `web/career`
3. Web Station → **Web Portal** → *Create* → **Portal by port**
   - לקשר לשירות שיצרת, ולבחור פורט — למשל `8080`
4. **File Station** → להעתיק את `index.html` לתיקייה שבחרת
5. מהטלפון: `http://<כתובת-ה-NAS>:8080`

לעדכון: פשוט להחליף את `index.html` ולרענן את הדף.

---

## הדרך השנייה: Container Manager

אם ממילא נוח לך עם קונטיינרים:

1. להעתיק ל-NAS את התיקייה `deploy/` **ואת** `web/index.html`,
   בשמירה על מבנה התיקיות
2. **Container Manager** → *Project* → *Create* → לבחור את `deploy/`
3. `http://<כתובת-ה-NAS>:8080`

הקובץ מחובר לקונטיינר לקריאה בלבד, אז עדכון הוא החלפת הקובץ
ורענון — בלי לבנות מחדש.

---

## הדבר האחד שחשוב להבין: הכתובת היא השמורה

הקריירה נשמרת בדפדפן, וכל דפדפן שומר **לפי הכתובת** שדרכה נכנסת.
המשמעות המעשית:

- `http://192.168.1.50:8080` ו-`http://nas.local:8080` הן **שתי
  שמורות נפרדות**, גם מאותו טלפון.
- כניסה מהטלפון ומהמחשב = שתי קריירות נפרדות, גם דרך אותה כתובת.

לכן: **לקבוע כתובת אחת ולהיצמד אליה.** כדאי לתת ל-NAS כתובת IP
קבועה בראוטר, לשמור סימנייה, ולהיכנס תמיד דרכה.

בטלפון כדאי להוסיף את הדף למסך הבית — בסאפארי דרך *שיתוף → הוספה
למסך הבית*, בכרום דרך התפריט. שתי הערות:

- זה נותן חוויה של אפליקציה, בלי סרגלי דפדפן.
- **בסאפארי, דף במסך הבית מקבל אחסון נפרד מהדפדפן.** אם כבר שיחקת
  בסאפארי, הקריירה לא תעבור לשם מעצמה — צריך להעביר אותה דרך קובץ
  ההעברה (מסך המערכת → *קובץ העברה*).

## גיבוי, עכשיו כשיש NAS

הדפדפן הוא לא מקום לשמור בו דברים לנצח: ניקוי נתוני גלישה מוחק את
הקריירה, וסאפארי מוחק אחסון של אתרים שלא נכנסת אליהם שבעה ימים.

מסך המערכת → **קובץ העברה** מוריד קובץ שמורה. שווה להוריד אותו
לתיקייה מסונכרנת ב-NAS מדי כמה עונות — אז גם אם הדפדפן יתאפס,
הקריירה תחזור דרך *לשחזר מקובץ גיבוי*.

בכרום ובאדג' במחשב אפשר לקשר את הקובץ פעם אחת, ומאותו רגע כל שמירה
דורסת אותו לבד. בטלפון זה ידני.

## פונטים

הדף מושך שני פונטים מ-Google Fonts. אם ל-NAS יש אינטרנט — הכל
נראה כמו שצריך. ברשת מנותקת הפונטים לא ייטענו והמשחק ייפול לפונט
המערכת: הכל עדיין קריא ועובד, רק הכותרות ייראו אחרת.
